## 商品管理

- 商品新增可空文本货号、单位（默认“件”）；搜索支持名称、货号及 SKU 条码，分类过滤与分页共同生效。
- 列表显示价格、标价毛利率及颜色、尺码、条码、库存；标价毛利率不代表真实成交利润。
- 编辑器支持颜色 × 尺码批量生成组合，已存在组合保留原 SKU；每个新增规格需要独立条码，可以补全空条码。
- 新增规格必须填写真实颜色、尺码和条码；未改变规格的历史商品仍可编辑基本资料。
- 商品与完整 SKU 列表由 `PUT /api/product/{id}/catalog` 在同一事务中保存，失败整体回滚。
- 已有 SKU 库存只读，后台只更新规格资料，不采纳旧表单中的库存值。新规格仍兼容原有初始库存录入。
- 删除商品或规格时检查库存、库存流水与订单引用；存在库存或历史引用时拒绝删除。
- 旧的商品、SKU 编辑接口保留，规格资料更新同样不会覆盖库存。生成条码先写入表单，取消编辑不会修改已有规格条码。

## 只读导入预览

入口为商品管理页“导入预览”，接口为 `POST /api/product/import/preview`，使用 multipart 的 `file` 字段。

支持 `.xls`、`.xlsx`，单次文件最大 5 MB、最多 5000 条规格记录和 20 个工作表。解析表头、跳过抬头、重复表头、空行及已识别的合计、页码、结束行；忽略全空字段及不映射的旧系统字段。数值 0 保留其数值含义，不视为空值。

预览识别货号、条码、名称、单位、成本价、零售价、颜色、尺码及来源分类。标识按文本展示并保留文本前导零；过长且已经可能丢失精度的数字标识报错。公式单元格不执行，映射字段中遇到公式会提示错误。缺失成本保持未知，不用 0 填补；售价必填。

| 状态 | 含义 |
|---|---|
| 可新增 | 本次检查通过，尚未写库 |
| 待补规格 | 颜色或尺码缺失，或仍为 `0无`、`0均码` 占位值 |
| 已有冲突 | 货号或条码与数据库记录冲突 |
| 数据错误 | 必填字段、金额、重复规格/条码或同货号商品资料不一致等问题 |

同一行有多个问题时，状态按数据错误、已有冲突、待补规格、可新增的顺序显示，说明中保留具体问题。页面支持状态筛选、每页 50 条记录及 Excel 源行号定位。

本轮没有导入确认按钮或提交写库接口。来源分类只作候选展示，不自动新建分类；“末入量”不映射库存，“扣%”不映射顾客折扣。

## 真实数据结果与后续整理

真实表格 `test1` 的第 4—223 行共 220 个货号、220 条记录；预览结果为 **待补规格 220、数据错误 0、已有冲突 0、可新增 0**。冲突数是在隔离的测试数据库中验证，连接实际业务数据库后会按其现有记录重新判断。

全部源颜色、尺码均为旧系统占位值，无法从表中恢复实物规格。后续按实际商品整理：同一货号每个真实颜色/尺码组合占一行，商品名称、价格、单位保持一致，各规格提供独立条码。原条码可以保留给其中一个对应规格，不能复制给所有规格。没有当前库存的数据不用于构造库存。

## 数据库升级

新库初始化的 `schema.sql` 已包含 `product_code`、`unit` 与货号唯一索引。**已有数据库必须在部署新版后端前执行增量脚本**：

`scripts/migrations/2026-09-16-product-catalog.sql`

脚本按当前选中的数据库检查列、索引是否存在，可重复执行；不会导入商品或改动 SKU 库存。执行前按原部署流程备份，确认数据库名称。该脚本只用于已有 `product` 表，不能替代新库初始化。

```bash

mysql -u YOUR_DB_USER -p clothing_pos < scripts/migrations/2026-09-16-product-catalog.sql
```

本轮没有对业务 MySQL 执行迁移或写入操作。
