# 页面文字重叠修复与检查记录

2026-09-17。用户反馈销售趋势底部图例和日期文字重叠。

## 原因与修复

项目当前安装的 ECharts 6 默认将图例放在底部，趋势图没有指定位置。已在隔离页面复现同样重叠：销售额、毛利图例覆盖日期轴；12 个分类的饼图图例同时遮挡外部标签。

- 销售趋势：显式将图例置顶，绘图区预留独立空间，日日期标签缩短为月日并隐藏碰撞标签；提示仍保留完整日期。
- 分类占比：图例在顶部独立区域分页，饼图预留空间，长名称截断、标签避让；提示保留完整分类信息。
- 报表布局：较窄窗口下图表上下排列、统计卡片换行；日期筛选控件限制宽度，控件间增加行列间距。
- 商品、订单：筛选栏改用统一间距；商品表单吸收栅格外边距，消除多余横向滚动。
- 收银：合计、折扣、应收和结账按钮可换行，防止相互挤压。
- 库存、设置：工具栏换行；分类长名称截断并提供完整名称提示，保留编辑按钮空间。
- 公共布局：主内容可收缩、分页可换行、弹窗限制宽度和可滚动内容；登录框限制最大宽度。

## 验证

通过单独的本机 Vite 实例加载实际 Vue 页面，API 使用虚构商品、订单、30 日趋势及 12 个长名称分类。测试实例不连接业务数据库，不执行商品保存、入库、收款、用户创建或打印。

| 检查 | 结果 |
|---|---|
| 1280 / 1024 / 768 像素宽度的报表 | 图例与日期分离；图表按宽度并排或上下排列 |
| 多分类饼图 | 分页图例与外部标签分离 |
| 768 像素下商品、库存、订单、设置、报表 | 检查筛选/工具栏子控件边界，无重叠或越界；主内容无页面级横向溢出 |
| 768 像素下有商品的收银页 | 结算栏无重叠或越界，表格在自身区域横向滚动 |
| 商品编辑、入库、订单详情、收款、新增用户弹窗 | 在窗口内，底部按钮可见，弹窗内容无额外横向溢出 |
| 前端生产构建 | `npm --prefix frontend run build` 通过，仍有原有的大包体积提示 |
| 改动格式 | `git diff --check` 通过 |

该检查覆盖上述尺寸与场景，不代表所有浏览器、任意极端字符串长度或手机尺寸均已验收。没有改变销售数据、金额计算、库存或数据库结构。
