# 经销商、颜色字典与 16 位条码实现说明

## 业务规则

- 商品固定归属一个经销商，货号在同一经销商内唯一。
- 经销商编码由系统从 `100` 起分配；颜色、尺码编码为两位且创建后不修改、不回收。
- `00` 分别表示“无颜色”和“均码”。旧表中的 `0无 / 0均码` 仍按待完善规格处理，不自动推断。
- 系统条码为 `经销商3位 + 货号6位 + 尺码2位 + 颜色2位 + 识别码3位`，共 16 位，使用 CODE128 打印。
- 相同前 13 位的识别码从 `001` 递增，计数保存在数据库中。Excel 和人工条码不强制符合该结构，但必须全局唯一。

## 页面与权限

- 新增一级“经销商管理”页面，仅管理员维护；所有登录用户可在商品表单选择启用的经销商。
- 系统设置的标签管理同时维护颜色和尺码。编码永久保留，所有配置通过启用/停用管理，不提供物理删除。
- 商品新增与完整编辑必须选择经销商、1—6 位数字货号、受管颜色和尺码，才能生成条码。
- 首次补全条码可正常执行；重新制码为管理员操作，并在页面明确提示旧标签失效。

## Excel 导入

导入继续采用“预览 → 确认”两阶段。系统从文件的“客商”抬头解析经销商，按“经销商 + 货号”检查冲突。经销商不存在时阻止导入，不自动创建。

`test111.xls` 中的“新旺角”对应编码 `100`。原 13 位条码原样保存，不转换为系统 16 位规则。确认导入只创建商品和 SKU，规格占位数据标记待完善，库存与库存流水均不写入。

```bash

```

迁移会将当前已确认的测试商品绑定到“新旺角”，并把真实的旧颜色、尺码名称纳入字典。具备经销商、数字货号及完整规格编码的 `HUAXING...` 测试条码会重建为16位条码；资料不完整的规格保持原样等待人工完善。Excel、人工条码和库存不会被改写。
